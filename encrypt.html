You’ve Failed a Phishing Test!
This was a simulated phishing email. Generac’s Security Team is monitoring results.

What went wrong:

  • Clicked a link in a message pretending to be from Generac.
  • Entered credentials or personal information on a site mimicking Generac’s appearance.
  • Did not verify the sender address or check the URL before clicking.

How to improve:

  • Check the sender’s email address—even if it looks familiar.
  • Hover over links to inspect the real URL.
  • If unsure, manually go to Generac’s official website instead of clicking links.
  • Report suspicious messages to IT / Security immediately.

Why it matters:

Phishing attempts can lead to leaked credentials, data breaches, or financial loss. Maintaining vigilance helps protect everyone at Generac.
